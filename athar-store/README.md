# متجر أثر

متجر عربي RTL متجاوب، بواجهة مستوحاة من طريقة عرض متجر نوريتا ولكن بهوية أصلية بالأسود والذهبي. المنتجات والفئات والأسعار والشحن والنصوص تُدار من ملف Excel، والصور تُرفع من لوحة الإدارة، والطلب النهائي يُرسل كاملًا إلى واتساب.

## التشغيل محليًا

```bash
npm install
ADMIN_PASSWORD="كلمة-مرور-قوية" npm start
```

ثم افتح:

- المتجر: `http://localhost:3000`
- لوحة الإدارة: `http://localhost:3000/admin`

في حالة عدم تعيين `ADMIN_PASSWORD` أثناء المعاينة فقط، كلمة المرور الافتراضية هي:

```text
athar-demo-2026
```

**يجب تغييرها قبل النشر.**

## إدارة المنتجات من Excel

1. ادخل لوحة الإدارة.
2. حمّل ملف Excel الحالي من قسم **ملف المنتجات والأسعار**.
3. عدّل الملف من غير تغيير أسماء الشيتات أو الأعمدة.
4. لإضافة صورة، ارفعها أولًا من قسم **رفع صور المنتجات**.
5. انسخ اسم الصورة من **مكتبة الصور** والصقه في عمود `الصورة الرئيسية`.
6. احفظ الملف بصيغة `.xlsx` وارفعه من لوحة الإدارة.
7. افتح المتجر أو حدّث الصفحة؛ التغييرات تظهر فورًا.

### الشيتات المتاحة

- **المنتجات:** الاسم، السعر، الخصم، الفئة، الوصف، الصور، التوفر، المنتج المميز والجديد.
- **الفئات:** أسماء وصور وترتيب الأقسام.
- **إعدادات المتجر:** رقم واتساب، نصوص الواجهة، صورة البانر، روابط التواصل والعملة.
- **الشحن:** المحافظة والتكلفة وإمكانية التوصيل.
- **آراء العملاء:** الاسم والنص والتقييم والظهور.
- **اقرأني أولًا:** تعليمات مختصرة داخل الملف نفسه.

## الطلب عبر واتساب

السلة تحفظ المنتجات في متصفح العميل. عند إتمام الطلب، يملأ العميل:

- الاسم
- رقم الهاتف
- المحافظة
- المدينة/المنطقة
- العنوان بالتفصيل
- ملاحظات اختيارية

ثم يفتح واتساب برسالة جاهزة تشمل المنتجات والكميات والأسعار والشحن والإجمالي، على الرقم الموجود في Excel. الرقم الحالي: `201030263241`.

## التخزين والنشر

ملف Excel محفوظ في:

```text
data/store.xlsx
```

والصور محفوظة في:

```text
public/uploads/
```

لأن لوحة الإدارة تكتب ملفات على الخادم، يجب استخدام استضافة تدعم **تخزينًا دائمًا**، مثل VPS أو خدمة بها Persistent Disk. لا تستخدم تخزينًا مؤقتًا من دون ربط Volume، وإلا قد تضيع التعديلات عند إعادة تشغيل الخدمة.

### Docker Compose

عدّل كلمة المرور في `docker-compose.yml` ثم شغّل:

```bash
docker compose up -d --build
```

تم إعداد Volume لكل من `data` و`public/uploads` للحفاظ على ملف Excel والصور.

## ملاحظات قبل الإطلاق

- غيّر كلمة مرور لوحة الإدارة.
- راجع أسعار الشحن التجريبية في Excel.
- استبدل المنتجات والصور والآراء التجريبية بالمحتوى الحقيقي.
- اربط الدومين وشهادة HTTPS.
- احتفظ بنسخة احتياطية دورية من `data/store.xlsx` ومجلد الصور.
