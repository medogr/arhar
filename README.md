# متجر أثر — نسخة GitHub Pages + Google Sheets

هذه النسخة ثابتة وتعمل على GitHub Pages، وتقرأ المنتجات والفئات والأسعار والشحن والنصوص من Google Sheets من دون API key.

## رابط Google Sheet المرتبط

```text
https://docs.google.com/spreadsheets/d/1HL412rGoEeD_8Sden1SqYZh3eTIyTg0JfSejmKOLKuc/edit
```

رقم الشيت محفوظ في `js/config.js`.

## مهم: الشيت ما زال فارغًا

وقت تجهيز هذه النسخة، الرابط يحتوي على تبويب فارغ اسمه «الورقة1». الموقع سيعرض البيانات التجريبية الاحتياطية من `data/store.json` إلى أن تستورد ملف القالب.

لاستيراد القالب:

1. افتح Google Sheet.
2. اختر **File / ملف** ثم **Import / استيراد**.
3. اختر **Upload / تحميل** وارفع `athar-google-sheets-template.xlsx`.
4. اختر **Replace spreadsheet / استبدال جدول البيانات**.
5. تأكد من ظهور التبويبات:
   - المنتجات
   - الفئات
   - إعدادات المتجر
   - الشحن
   - آراء العملاء
6. من **Share / مشاركة** اختر **Anyone with the link — Viewer**.
7. حدّث الموقع. قد تستغرق تغييرات Google من دقيقة إلى دقيقتين.

## رفع الملفات إلى GitHub بطريقة صحيحة

1. فك ضغط `athar-github-pages-ready.zip` على جهازك.
2. من الصفحة الرئيسية لمستودع `arhar` اختر **Add file → Upload files**.
3. ارفع **محتويات المجلد بعد فك الضغط** إلى جذر المستودع، وليس المجلد نفسه. يمكن ترك مجلد `athar-store` القديم مؤقتًا؛ لن يمنع التشغيل.
4. يجب أن يظهر `index.html` مباشرة في الصفحة الرئيسية للمستودع بجانب مجلدات `assets`, `css`, `data`, `js`, `uploads`.
5. من GitHub: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
6. انتظر دقيقة أو دقيقتين ثم افتح:

```text
https://medogr.github.io/arhar/
```

## تعديل المنتجات

عدّل تبويب **المنتجات** في Google Sheets. لا تغيّر أسماء الأعمدة أو أسماء التبويبات.

- `متوفر`: نعم أو لا.
- `مميز`: نعم أو لا.
- `وصل حديثًا`: نعم أو لا.
- `الترتيب`: رقم ترتيب ظهور المنتج.
- `الصورة الرئيسية`: اسم ملف محلي أو رابط صورة مباشر/Google Drive.
- `صور إضافية`: عدة أسماء أو روابط مفصولة بفاصلة.

## إضافة الصور

### الطريقة الأولى: GitHub

1. افتح مجلد `uploads` في المستودع.
2. اختر **Add file → Upload files**.
3. ارفع الصورة باسم إنجليزي واضح مثل `black-notebook.jpg`.
4. اكتب الاسم نفسه في عمود الصورة داخل Google Sheets.

### الطريقة الثانية: Google Drive

1. ارفع الصورة إلى Drive.
2. اجعلها **Anyone with the link — Viewer**.
3. الصق رابط المشاركة كاملًا في عمود الصورة.

الموقع يحوّل رابط Google Drive تلقائيًا إلى صورة قابلة للعرض.

## التحديث والنسخة الاحتياطية

- يتم فحص Google Sheets عند فتح/تحديث الصفحة.
- يوجد تخزين مؤقت لمدة دقيقتين لتقليل الطلبات.
- إذا كان Google Sheet فارغًا أو غير متاح، يعرض الموقع تلقائيًا بيانات `data/store.json` بدل ظهور صفحة مكسورة.
- احتفظ دائمًا بنسخة Excel من بياناتك.
